# 参数与判据

## 对话框几何（最大化 1920×1080，实测）

写入方式统一为 `SendMessageW(hwnd, 0x000C /*WM_SETTEXT*/, 0, "值")`，
提交为 `SendMessageW(okHwnd, 0x00F5 /*BM_CLICK*/, 0, 0)`。

### `FM/VCO (Token 1)` — 对话框 (753,336) ~ (1169,745)

| 字段 | 矩形 | 含义 |
|---|---|---|
| Amplitude (v) | (779,404)-(945,463) | 载波幅度 |
| **Mod Gain (Hz/v)** | (974,404)-(1140,463) | 灵敏度 $K_f$，单位 Hz/V |
| **Frequency (Hz)** | (779,520)-(945,579) | 载波频率 $f_c$ |
| Phase (deg) | (779,638)-(945,697) | 初相 |
| OK / Cancel | (996,620)-(1097,661) / (996,670)-(1097,711) | |

瞬时频率：$f_i(t) = f_c + K_f\,m(t)$，调制度 $\Delta f = K_f \cdot \max|m|$，
调制指数 $\beta = \Delta f / f_m$。

### `Sinusoid (Token 0)` — 对话框 (751,336) ~ (1169,745)

Amplitude (778,404)-(944,463)、**Frequency (778,520)-(944,579)**、Phase (778,638)-(944,697)、
OK (996,504)-(1097,545)、Cancel (996,670)-(1097,711)。

### `Delay: Continuous (Token 8)` — 对话框 (751,390) ~ (1167,690)

`Delay Type`：`Non-Interpolating` / `Interpolating`；`Delay (sec)`。实测 **250e-6，Interpolating**。

判据：延迟线鉴频器要求载波经延迟后相移约 90°，
$$2\pi f_c \tau \approx \tfrac{\pi}{2} + k\pi$$
本例 $f_c\tau = 5000 \times 250\mu = 1.25$ → $2\pi \cdot 1.25 = 2.5\pi \equiv 90°$，正好命中。

### `SystemView Linear System (t10 Butterworth IIR)` — 对话框 (529,234) ~ (1392,848)

4 阶 Butterworth IIR 低通，分子系数
`0.108499448185169 / 0.325498344555508 / 0.325498344555508 / 0.108499448185169`，
分母 `1 / -0.480709163547723 / 0.394605575830942 / -4.59008268018632e-02`。

### `Gaussian Noise (Token 7)`

`Std Deviation (v)`（默认 `10e-3`）、`Mean (v)`、`Apply to tokens`。
**只能从 `Edit Parameters...` 进；从 Source Library 的 OK 进会被重置。**

## 怎么判断"波形能不能体现调频"

三条同时满足才看得见：

1. **不欠采样**：$f_c < f_s/2$。本例 $f_s = 24$ kHz，所以 $f_c < 12$ kHz。
2. **每像素不超过 1–3 个载波周期**：1.34 s 铺 800 px 时每像素 1.7 ms，
   $f_c = 5$ kHz 就是每像素 8.4 个周期 → 必然是实心块。要放大到 **≤5 ms** 的窗口
   （鼠标在波形区框选拖拽即缩放）。
3. **调制指数够大**：$\beta = \Delta f / f_m \ge 1$。语音+`K_f=10` 时 $\Delta f$ 只有 ±300 Hz，
   相对 5 kHz 只有 6%，即使放大也几乎看不出疏密。

同时还要保证**解调仍然正常**（否则图好看但结论是错的）：`w3` 两路接近重合、`w5` 单峰窄。

## 本例调参的实测边界

| $K_f$ | $f_c$ | 结果 |
|---|---|---|
| 10（原始） | 5000 | 解调正常，但已调波看不出疏密 |
| 30（演示用） | 5000 | 疏密清晰，`w3` 118–138、`w5` 118–138，**可用** |
| 50 | 2000 | `w3` 炸成 0–200 实心块、`w4` 铺满 12 kHz → 鉴频失效 |
| 100 | 5000 | `w3` 变 105–150 噪声带 |
| 2000 | 5000 | 完全崩坏 |
| 20 | 2500 | 载波太低，`w5` 塌到 0 附近，鉴频中心不对 |

原因：音频源是 8-bit 无符号 PCM，带约 127 的直流。$f_i = f_c + K_f(127 + m)$ 会整体抬高，
$K_f$ 一大就顶到奈奎斯特区，鉴频器失效。**改 $K_f$ 必须连带看 `w3`/`w5` 是否还正常。**
